# Aleksei Subbotin

**Embedded Electronics & Power Control Developer — France / Remote**

I design, build, program, and debug embedded-electronics prototypes, measurement
and protection systems, and power-control hardware. My repositories include
working bench-tested devices as well as clearly labelled engineering prototypes.

## What I work with

- STM32F1, STM32G4, AVR, and Arduino Nano firmware in C
- STM32CubeIDE, STM32CubeMX, HRTIM, ADC, DAC, OPAMP, and comparators
- SPI, I2C, software I2C, TFT displays, rotary encoders, and device interfaces
- voltage and current measurement, shunt sensing, protection, and CC/CV control
- KiCad and EasyEDA schematics and PCB layout
- prototype assembly, hardware bring-up, troubleshooting, and bench validation
- modernization and documentation of existing electronic designs
